# GeminiWear for Wear OS 🤖⌚

A native Google Gemini client & voice assistant app designed specifically for Wear OS (circular display, Xiaomi Watch 2).

## Features
- **Voice & Text Input:** Ask Gemini questions using speech recognition or watch keyboard.
- **Image Recognition / Multimodal:** Send images or screenshots to Gemini for analysis.
- **Model Switching:** Switch between Gemini Flash and Pro models.
- **Custom Wear UI:** Optimized for circular screens with high readability bubbles.

## Installation
- Pobierz gotowy plik APK z sekcji [Releases](../../releases) lub bezpośrednio z repozytorium: [`build/apk/GeminiWear.apk`](build/apk/GeminiWear.apk).
- Zainstaluj przez ADB:
  ```bash
  adb install -r build/apk/GeminiWear.apk
  ```
